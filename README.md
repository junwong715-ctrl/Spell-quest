# Spell Quest

Spell Quest 係一個小學二年級英文拼字遊戲（單檔 HTML RPG）。小朋友可以一邊聽英式英文發音，一邊練習拼寫 Cambridge Starters／Movers 程度嘅詞彙。

## 點樣玩

1. 打開網頁，喺地圖揀一個已解鎖嘅關卡。
2. 撳 **Play** 聽英文生字，再打出正確拼法。
3. 拼啱就會攻擊怪物；錯得少可以攞到更多星星。
4. 通關之後會解鎖下一關。最後一關係 Dragon Castle。
5. 可以調校語速同英文語音。需要時可以重設進度。

進度會儲存在瀏覽器入面，唔使登入。
